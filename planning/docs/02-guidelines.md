# Planning Guidelines

> 1인 연습용 워크스페이스 기준 (2026-10-01, 채진성 답변으로 작성).

## Data & sourcing

- 근거를 먼저 찾는 곳: **크몽 경쟁 서비스**(가격·구성·후기), **크몽 공식 안내**(카테고리 설명·평균 단가)
- 출처 표기: **연습 단계라 형식은 따로 정하지 않음.** 가상 브랜드의 메뉴·가격·이야기 같은 내용은
  지어낸 것이라 출처가 필요 없음
- 검증 기준: 크몽·시장에 대한 주장은 **출처가 있으면 검증된 것**, 없으면 `[ASSUMPTION]` 표시

## Writing conventions

- 목표는 측정 가능한 결과로 적는다 (예: "제작 시간 측정"이 아니라 "3번째 연습에서 제작 시간이 1번째보다 줄었는지 비교").
- 기획 문서에는 무엇을 왜 만드는지만 적고, 구현 세부는 루트의 `docs/02-specs.md`로 보낸다.

## Glossary

- 소개형: 메뉴·영업시간·위치 등 정보를 보여주는 페이지 (예약·결제 없음)
- 전환형: 상담 신청·구매 등 손님의 행동을 받는 랜딩페이지
- 연습 N번: `docs/prd/00-index.md`의 연습 순서

## Review & approval flow

Status values used across `docs/prd/`: `Draft` → `In Review` → `Approved`
→ `Shipped` / `Shelved`.

- `Approved` 결정: **채진성 본인**
- 외부 공개(크몽 등록, 포트폴리오 게시) 전: **다른 사람의 피드백을 받은 뒤** 공개
