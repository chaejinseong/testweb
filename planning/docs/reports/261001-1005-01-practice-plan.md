- Date: 2026-10-01
- Author: agent (이전 대화 정리)
- Related initiative: docs/prd/00-index.md

## Decision

가상 가게 3곳(카페 → 필라테스·네일샵 → 개인 포트폴리오) 순서로 연습 페이지를 만들고,
매번 제작 시간을 잰다.

## Why

- 세 가지가 구조가 달라서, 끝내면 소상공인 요청 대부분을 비슷한 패턴으로 처리 가능
- 실제 브랜드는 상호·로고 무단 사용 문제가 있고 크몽 심사에서 반려될 수 있음
- 3번째쯤 걸린 시간이 가격 책정 기준이 됨

## Alternatives considered

- 실제 브랜드로 연습 → 저작권·크몽 반려 위험으로 제외
