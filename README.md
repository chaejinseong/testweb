# kmong-practice

크몽 외주 연습용 워크스페이스. 기획·작업 문서와 코드를 한 폴더에 둔다.

```
kmong-practice/
├─ AGENTS.md      작업(코딩) 지침 — docs-template
├─ SPEC.md        연습 1번 작업 계획과 진행 상황
├─ docs/          작업 문서 — 스펙, 폴더 구조, todo, reports
├─ planning/      기획 지침과 기획 문서 — planning-docs-template
├─ frontend/      React + Vite
└─ backend/       Node.js + Express
```

- 기획할 때는 `planning/AGENTS.md`, 코딩할 때는 루트의 `AGENTS.md`를 먼저 읽는다.
- 실행 명령은 `docs/02-specs.md`의 Commands 참고. 받은 뒤 `frontend/`, `backend/`에서 각각 `npm install`.

연습 순서: 카페(느린오후 커피) → 필라테스·네일샵 → 개인 포트폴리오. 매번 제작 시간 측정.
