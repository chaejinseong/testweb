# 연습 1번: 동네 카페 "느린오후 커피" 소개 사이트

> 바로 작업 폴더(루트의 `SPEC.md`, `docs/`)로 넘어갑니다.

## The headline

동네 손님이 휴대폰으로 사이트를 열면 **메뉴·가격, 영업시간, 위치, 가게 소식**을 바로 확인하고,
궁금한 건 **문의하기**로 사장님에게 바로 물어볼 수 있다.

## The problem

- [ASSUMPTION] 작은 동네 카페는 메뉴와 영업시간 정보가 인스타 게시물, 지도 앱 리뷰 사진 등에 흩어져 있어서 손님이 찾기 번거롭다.
- 연습 목적상 실제 고객 인터뷰는 없음. 이 문제는 검증된 사실이 아니라 가정이다.

## The solution

모바일 우선 **5페이지** 사이트 (React + Node.js):

| 경로 | 페이지 | 담는 내용 |
|---|---|---|
| `/` | 홈 | 상단 소개(이름·한 줄 소개·대표 사진), 메뉴 미리보기, 영업시간, 위치+연락처(주소·지도·인스타·전화) |
| `/menu` | 메뉴 | 커피·음료·디저트 전체 + 가격 |
| `/story` | 가게 이야기 | 사장님 이야기, 원두·로스팅 소개 |
| `/news` | 공지/소식 | 휴무·신메뉴·이벤트 안내 목록 |
| `/contact` | 문의하기 | 단체 주문·대관 등 문의 폼 → Node.js 서버가 사장님 이메일로 전달 |

예약·주문·결제는 넣지 않는다. 문의하기가 유일한 전환 요소다.

- 가상 브랜드: **느린오후 커피**. 웹 검색으로 같은 이름의 가게는 바로 보이지 않았지만, 전수 확인은 아님 [ASSUMPTION]
- 분위기: **모던한** (흰색·검정 위주, 넓은 여백, 깔끔한 고딕). 2026-10-01 채진성 결정 (기본값 "아늑한"에서 변경)
- 메뉴·가격·주소·소식은 모두 가상. 지도는 실존 가게와 겹치지 않는 예시 위치로 처리
- 이미지: 무료 상업용(Unsplash 등) 또는 AI 생성 이미지만

## Why now

크몽에 판매를 올리기 전에 포트폴리오 샘플 1개와 "사이트 하나 만드는 데 걸리는 시간" 기준이 필요하다.
(참고: 크몽 랜딩페이지 평균 비용 30만 원대 — https://kmong.com/prices)

## Biggest open question / risk

1. **소개형 카페 사이트가 크몽 포트폴리오로 쓸모가 있는가.** 크몽 랜딩 카테고리는 전환형 중심이다
   (https://kmong.com/category/632). 문의하기 폼이 전환 요소를 조금 보완한다.
2. **초보에게 범위가 커졌다.** 처음 원페이저는 1페이지였는데 5페이지 + 이메일 발송 서버로 늘었다.
   제작 시간이 예상보다 길어질 수 있으니, 막히면 문의 발송부터 뒤로 미룬다.
